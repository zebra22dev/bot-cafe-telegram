# bot-cafe-telegram ☕

Versão Telegram do bot de promoções de café: monitora Promobit, Gatry e canais de promoção no Telegram, compara com o menor preço do Buscapé e avisa no Telegram.

- Ajustes: edite `config.json` (palavras-chave, exclusões, lista de desejos, `abaixo_do_mercado_pct`).
- Roda sozinho a cada ~10 minutos pelo GitHub Actions.
- Precisa do secret `TELEGRAM_TOKEN` (token do @BotFather). O chat é descoberto sozinho depois que você manda /start para o bot.
